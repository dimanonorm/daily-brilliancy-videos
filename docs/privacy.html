Privacy Policy

Last updated: 17 October 2026

Daily Brilliancy Uploader ("the app") is a personal automation tool operated by the owner of the Daily_Brilliancy channel. It is used only with the owner's own YouTube channel and TikTok account.

What data the app accesses

  • YouTube (Google): with the owner's permission, the app uses the YouTube Data API to upload the owner's own videos and to post comments on the owner's own videos. It reads the list of the channel's own uploads to know which videos already have a comment.
  • TikTok: with the owner's permission, the app uses TikTok's Content Posting API and basic profile information to post the owner's own videos to the owner's account.

How data is stored

The only data stored are the OAuth access/refresh tokens needed to act on the owner's behalf. They are kept as encrypted secrets in the owner's GitHub repository and are never shared with anyone. The app does not collect, sell or share any personal data of other users or viewers.

Use of Google user data

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Data retention and deletion

The app keeps no copies of YouTube data other than the IDs of the owner's own videos (to remember which ones already have the comment). These IDs are stored in the owner's repository and can be deleted at any time. OAuth tokens are deleted by removing the repository secrets or revoking access as described below. The app uses no cookies and no analytics.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions (Google) or in TikTok's settings under "Security → Manage app permissions". Deleting the repository secrets removes all stored tokens.
