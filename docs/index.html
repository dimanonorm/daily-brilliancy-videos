Daily Brilliancy Uploader

▶ YouTube  This tool uses YouTube API Services.

Daily Brilliancy Uploader is a private, single-user tool run by the owner of the Daily_Brilliancy chess Shorts channel. It is used only with the owner's own accounts to:

  • upload the owner's own short chess videos (Shorts) to the owner's own YouTube channel, with the title, description and hashtags the owner prepared;
  • post one comment written by the owner (“Why is this move brilliant?”) under the owner's own videos;
  • read the list of the channel's own uploads to know which videos still need that comment.

The tool runs as a scheduled job in the owner's GitHub repository. It has no public sign-up, no other users, and it does not access, store or share any data of viewers or other channels.
